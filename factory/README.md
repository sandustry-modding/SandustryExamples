# Factory

These samples add structures, machines, pipes, and collector payout.
The beacon sprite is `mod/beacon.png`.
The scanner sprite is `mod/processor.png`.

| Folder | Try this | API |
| --- | --- | --- |
| `structure/` | Debug → Building → Example Beacon | `api.structures` |
| `processing/` | Scanner counts filled cells | `api.structures.processing` |
| `recipes/` | Grower, shaker, and kinetic press | `api.processing` |
| `behaviors/` | Beacon acts as a conveyor | `api.structureBehaviors` |
| `pipes/` | Overlay: pipe at the mouse | `api.pipes` |
| `factory/` | Overlay: level and shake count | `api.factory` |
| `authorization/` | Overlay: can build at the mouse | `api.authorization` |
| `building/` | Overlay: cancel placement | `api.building` |
| `blueprints/` | Overlay: serialize the mouse cell | `api.blueprints` |
| `collector/` | Overlay: Platinum collector value | `api.collector` |
