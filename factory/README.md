# Factory

These samples add structures, machines, pipes, and collector payout.
The beacon sprite is `mod/beacon.png`.
The scanner sprite is `mod/processor.png`.

| Sample | Try this | API |
| --- | --- | --- |
| `structure.ts` | Debug → Building → Example Beacon | `api.structures` |
| `processing.ts` | Scanner counts filled cells | `api.structures.processing` |
| `recipes.ts` | Grower, shaker, and kinetic press | `api.processing` |
| `behaviors.ts` | Beacon acts as a conveyor | `api.structureBehaviors` |
| `pipes.ts` | Overlay: pipe at the mouse | `api.pipes` |
| `factory.ts` | Overlay: level and shake count | `api.factory` |
| `authorization.ts` | Overlay: can build at the mouse | `api.authorization` |
| `building.ts` | Overlay: cancel placement | `api.building` |
| `blueprints.ts` | Overlay: serialize the mouse cell | `api.blueprints` |
| `collector.ts` | Overlay: Platinum collector value | `api.collector` |
