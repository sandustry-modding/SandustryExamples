# Player

Press **Z** to teleport.
Other player samples are overlay buttons or status lines.

| Folder | Try this | API |
| --- | --- | --- |
| `player/` | Press **Z** | `api.player.setPositionAtWorld` |
| `inventory/` | Overlay: Has grabber | `api.player.inventory` |
| `buildings/` | Unlocks the beacon | `api.player.buildings` |
| `tools/` | Overlay: grabber size | `api.tools.grabber` |
| `camera/` | Overlay: snap the camera | `api.camera` |
| `action/` | Overlay: active hotbar action | `api.action` |
| `items/` | Registers Example Token | `api.items` |
| `cooldown/` | Overlay: start a 1s cooldown | `api.cooldown` |
