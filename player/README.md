# Player

Press **Z** to teleport.
Other player samples are overlay buttons or status lines.

| Sample | Try this | API |
| --- | --- | --- |
| `player.ts` | Press **Z** | `api.player.setPositionAtWorld` |
| `inventory.ts` | Overlay: Has grabber | `api.player.inventory` |
| `buildings.ts` | Unlocks the beacon | `api.player.buildings` |
| `tools.ts` | Overlay: grabber size | `api.tools.grabber` |
| `camera.ts` | Overlay: snap the camera | `api.camera` |
| `action.ts` | Overlay: active hotbar action | `api.action` |
| `items.ts` | Registers Example Token | `api.items` |
| `cooldown.ts` | Overlay: start a 1s cooldown | `api.cooldown` |
