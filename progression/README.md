# Progression

These samples add tech, upgrades, and discoveries.
The objective button is in the overlay.

| Folder | Try this | API |
| --- | --- | --- |
| `tech/` | Tech node under Signal Devices | `api.tech` |
| `conservatory/` | Beacon on that tech unlock | `api.tech.conservatory` |
| `upgrades/` | Overlay: upgrade level | `api.upgrades` |
| `discoveries/` | Spark Dust and Example Chalk | `api.discoveries` |
| `progression/` | Overlay: complete objective `all` | `api.progression` |
