# Progression

These samples add tech, upgrades, and discoveries.
The objective button is in the overlay.

| Sample | Try this | API |
| --- | --- | --- |
| `tech.ts` | Tech node under Signal Devices | `api.tech` |
| `conservatory.ts` | Beacon on that tech unlock | `api.tech.conservatory` |
| `upgrades.ts` | Overlay: upgrade level | `api.upgrades` |
| `discoveries.ts` | Spark Dust and Example Chalk | `api.discoveries` |
| `progression.ts` | Overlay: complete objective `all` | `api.progression` |
