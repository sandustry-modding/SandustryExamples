# World and simulation

These samples change cells, materials, digging, or simulation time.
`api.world` is a deprecated alias of `api.grid`.
Use `grid.ts`.

| Sample | Try this | API |
| --- | --- | --- |
| `grid.ts` | Overlay: read the cell under the mouse | `api.grid` |
| `maps.ts` | Overlay: active map or map count | `api.maps` |
| `excavation.ts` | Registers a dig profile | `api.excavation` |
| `fire.ts` | Overlay: burn the cell under the mouse | `api.fire` |
| `patterns.ts` | Overlay: circle stamp size | `api.patterns` |
| `random.ts` | Overlay: roll 1–6 | `api.random` |
| `raycast.ts` | Overlay: raycast to the right | `api.raycast` |
| `constants.ts` | Overlay: physics skip mode | `api.constants` |
| `workers.ts` | Turns worker post-update on | `api.workers` |
| `hooks.ts` | Counts Escape. Movement modify passes through | `api.hooks` |
| `events.ts` | Counts ready and building placed | `api.events` |
| `schedule.ts` | Press **G** | `api.schedule` |
| `triggers.ts` | Overlay counter every 300 ticks | `api.triggers` |
| `element.ts` | Debug → Element → Spark Dust | `api.elements` |
| `collector-element.ts` | Press **P**. Collector value 2 | `api.elements` |
| `terrain.ts` | Debug → Terrain → Example Chalk | `api.terrains` |
| `reaction.ts` | Sand plus water becomes wet sand | `api.reactions` |
