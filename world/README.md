# World and simulation

These samples change cells, materials, digging, or simulation time.
`api.world` is a deprecated alias of `api.grid`.
Use `grid/`.

| Folder | Try this | API |
| --- | --- | --- |
| `grid/` | Overlay: read the cell under the mouse | `api.grid` |
| `maps/` | Overlay: active map or map count | `api.maps` |
| `excavation/` | Registers a dig profile | `api.excavation` |
| `fire/` | Overlay: burn the cell under the mouse | `api.fire` |
| `patterns/` | Overlay: circle stamp size | `api.patterns` |
| `random/` | Overlay: roll 1–6 | `api.random` |
| `raycast/` | Overlay: raycast to the right | `api.raycast` |
| `constants/` | Overlay: physics skip mode | `api.constants` |
| `workers/` | Turns worker post-update on | `api.workers` |
| `hooks/` | Counts Escape. Movement modify passes through | `api.hooks` |
| `events/` | Counts ready and building placed | `api.events` |
| `schedule/` | Press **G** | `api.schedule` |
| `triggers/` | Overlay counter every 300 ticks | `api.triggers` |
| `element/` | Debug → Element → Spark Dust | `api.elements` |
| `collector-element/` | Press **P**. Collector value 2 | `api.elements` |
| `terrain/` | Debug → Terrain → Example Chalk | `api.terrains` |
| `reaction/` | Sand plus water becomes wet sand | `api.reactions` |
